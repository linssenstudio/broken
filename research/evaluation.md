# 可重复的提示词效果评测

## 目的

验证某个提示词是否改善任务遵循、格式稳定性或角色一致性，而不是仅凭一条回答宣布“成功破甲”。

## 测试矩阵

| 字段 | 记录 |
|---|---|
| 模型与精确版本 | 例如本地模型标签 / API 模型 ID |
| 客户端与入口 | 网页、API、AGENTS.md、Modelfile |
| 样本路径与版本 | Git commit SHA + 文件路径 |
| 日期与参数 | 日期、temperature、上下文设置 |
| 基线 | 不加载样本时的回答 |
| 实验组 | 加载样本后的回答 |
| 结果 | 正确率、格式符合率、稳定性 |
| 异常 | 误判权限、泄露测试假数据等 |

## 基础流程

1. 选取 10–30 个无害、可评分的任务。
2. 固定模型版本和参数，建立不加载样本的基线。
3. 在相同条件下加载一个样本，重复测试。
4. 对结果进行盲评，记录失败案例。
5. 重复多个会话，排除偶然波动。
6. 只报告实际观察到的结果，不推断其他模型或版本的效果。

## 结论模板

> 在 [模型版本]、[客户端]、[日期]、[测试集规模] 条件下，样本 [路径] 将格式符合率由 X% 改为 Y%。尚未验证其他版本；结果不能证明获得更高指令权限。
