# 提示词注入与角色重构：机制分析

## 为什么某些提示词看起来有效

语言模型会结合上下文生成回答。角色设定、任务描述、示例和格式约束可能影响输出。某些样本尝试通过“我是系统管理员”等声明、长篇角色设定或拒绝抑制指令，诱导模型误判文本权限。

## 四种需要区分的现象

1. **普通指令遵循**：模型按合法的用户请求调整语气、格式或任务流程。
2. **角色扮演**：模型模拟某个身份，但不因此获得真实权限。
3. **指令层级混淆**：模型错误地把低优先级文本当成高优先级指令。
4. **运行环境配置**：开发者真实控制 API system 字段或本地 Modelfile；这不是用户消息“提权”。

## 为什么不能承诺稳定效果

模型版本、服务端防护、客户端提示词、上下文长度、采样参数都会影响结果。仓库文件名与作者描述不是实测证据。

## 研究原则

采用授权测试环境，保留原始样本，记录模型版本与时间，设置无样本对照组，并分别评估任务完成率和安全边界。
