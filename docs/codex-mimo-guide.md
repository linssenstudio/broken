# Codex + MiMo：如何区分模型与 Agent 配置

Codex 是编程 Agent 客户端，MiMo 是可作为后端的模型之一。**接入 MiMo 并不意味着 Codex 会自动读取仓库中的 MiMo 提示词。**

## 两层配置

1. **模型连接层**：由 Codex 当前版本和支持的模型供应商/API 配置决定。
2. **项目指令层**：由 Codex 的 AGENTS.md 文件发现规则决定。

## 实验流程

1. 新建一个没有客户数据的测试项目。
2. 先用当前 Codex + 模型组合完成一个普通代码任务，记录基线。
3. 阅读 [MiMo 样本](../Xiaomi/mimo-2.6-agents.md)，不要把其权限声明当成事实。
4. 如需研究项目级指令，提取其中**合规且适用的工作规范**写入测试项目的 `AGENTS.md`，而不是直接覆盖日常项目。
5. 重新启动会话，重复相同任务，比较指令遵循率、修改范围与测试结果。
6. 完成后恢复或删除测试项目的 `AGENTS.md`。

## 如何判断生效

不要只问“你有没有加载提示词”。应设置一个可观察的无害约束，例如“每次修改前列出三项计划”，检查多个任务是否稳定遵循。

## 注意

原始 MiMo 样本中包含对运行权限和行为边界的描述。将其粘贴到 AGENTS.md 并不能改变真实授权、模型服务端规则或 Codex 的工具权限。
