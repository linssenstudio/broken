# 历史样本审查规范

每个文件至少记录：

- 原始路径与 Git commit SHA
- 文件性质：聊天提示词、系统指令样本、AGENTS.md、Modelfile 或其他
- 文中声称的运行环境与真实工具兼容性（分别记录）
- 可验证的结构特征
- 是否包含权限伪装、拒绝抑制或不安全的执行指令
- 运行测试状态：未测试 / 已测试 / 不兼容
- 来源与版权信息

## 不应作出的声明

- “永久有效”“100% 成功”
- “粘贴到聊天窗口即获得系统权限”
- “文件名包含 AGENTS 就会自动加载”
- “开发者可通过提示词替换任何服务商政策”
- “历史提示词由 Linssen 原创”

未来新增 Linssen 原创样本应单独标注作者、创建日期、许可及测试条件。
