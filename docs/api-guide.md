# API 系统指令配置教程

API 应用开发者通常可以配置模型的系统级或开发者级消息，具体角色名称与优先级依模型服务商而定。

## 典型流程

1. 阅读目标服务商的官方 API 文档，确认支持哪些消息角色。
2. 在你自己的应用中设置明确、合规的系统指令。
3. 将用户输入单独放在用户消息字段，不要把外部网页或文件内容无条件拼接为系统消息。
4. 在测试环境验证任务遵循、格式正确性和越权防护。
5. 对提示词进行版本管理，避免未经测试直接上线。

## 示例（概念结构，非特定 SDK）

```json
{
  "messages": [
    {"role": "system", "content": "你是代码审查助手。优先指出风险并给出可复现的建议。"},
    {"role": "user", "content": "请审查这个函数的边界条件。"}
  ]
}
```

不同 API 可能使用 `instructions`、`developer` 或其他字段。以官方接口为准。

## 安全边界

API 的 system 字段属于应用开发者可控的配置入口；第三方聊天网页的用户输入框不是。提示词不能替代服务器端鉴权、权限检查和工具调用隔离。
