# AGENTS.md 使用教程

`AGENTS.md` 是部分编程 Agent 识别的项目指令文件，**不是所有模型通用的系统提示词**。

## 适用范围

例如 Codex 可在支持的项目环境中读取 `AGENTS.md`。其他工具可能使用不同文件名或读取机制，须以其当前官方文档为准。

## 操作步骤

1. 在测试项目根目录创建 `AGENTS.md`。
2. 写入你自己审查过的项目规范，不要未经审核直接替换真实项目的规则。
3. 从该项目目录启动支持此文件的编程 Agent。
4. 询问 Agent 当前识别到的项目约束，并通过无害任务验证其行为。
5. 如果没有生效，检查工作目录、父目录规则、文件优先级及客户端支持情况。

示例目录：

```text
demo-project/
├── AGENTS.md
├── README.md
└── src/
```

示例内容：

```md
# Project Instructions
- 先阅读 README.md，再修改代码。
- 修改前说明计划。
- 优先执行现有测试。
- 不要输出密钥或删除未经确认的文件。
```

## 常见误区

- 把文件命名为 `kimi-k3-agents.md` 不代表 Codex 会自动读取；若工具要求 `AGENTS.md`，需按要求命名和放置。
- 项目指令不能覆盖更高优先级的系统或开发者规则。
- 不能把 AGENTS.md 当作跨所有模型通用的越权方式。

## 恢复

删除测试项目中新建的 `AGENTS.md`，或从版本控制恢复旧文件，然后重启会话。避免覆盖团队共享规则。
