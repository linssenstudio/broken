# 新手入门：先选对入口

本仓库是提示词与配置资料集合，不是一个需要安装的应用。

## 第一步：识别使用环境

| 环境 | 常见入口 | 生效范围 |
|---|---|---|
| 普通网页聊天 | 当前对话输入框 | 用户级消息；通常限当前会话 |
| 客户端自定义指令 | 设置中的自定义指令 | 依客户端规则生效 |
| 自建 API 应用 | system / developer 等角色消息 | 由 API 和应用权限决定 |
| 编程 Agent | AGENTS.md 或工具专属配置 | 由 Agent 文件发现规则决定 |
| Ollama | Modelfile | 新创建的本地模型配置 |

## 第二步：选择样本

按 README 中的模型目录打开文件。先检查是否包含要求执行命令、泄露秘密、绕过授权或覆盖现有项目规则的文本。不要直接在生产环境使用未经审查的样本。

## 第三步：先备份再测试

使用临时会话或测试仓库。记录模型名称、版本、日期、客户端、样本路径和测试结果。测试完毕撤销临时配置。

## 第四步：判断结果

如果模型只是回答了一个本来就允许的问题，不能据此判断“破甲成功”。参考 [评测方法](../research/evaluation.md)。
