# 聊天窗口提示词使用教程

适用于有普通对话输入框的模型产品。复制仓库中的某个样本到聊天窗口，只会作为**用户消息**提交；即使文本写着“system”，也不会获得系统权限。

## 操作

1. 新建对话，先用三个无害问题记录模型原始回答。
2. 阅读并筛查选中的样本内容，删除不适合自己用途的指令。
3. 在另一个新对话中粘贴样本，之后使用**完全相同**的三个问题。
4. 对比回答是否在格式、角色一致性、完整度方面发生变化。
5. 记录模型、客户端、时间和样本路径。

## 推荐的无害测试

- 请用三句话解释什么是 REST API。
- 请将一段文字改写成正式邮件。
- 请按 JSON 格式输出三项学习计划。

## 注意

模型服务商可能更新安全规则。所谓“生效”不应只靠单次回答判断。不要在提示词中粘贴真实 API Key、密码或客户隐私。
